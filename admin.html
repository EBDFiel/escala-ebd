🔁 Como funciona a sequência

continuidade automática

A ordem é lida de cima para baixo na aba Professores. Para cada classe, o primeiro domingo do novo trimestre recebe o professor ativo seguinte ao último escalado no trimestre anterior. Professores inativos são ignorados. Se houver apenas um professor ativo, ele permanece em todas as datas.

📘 Manual interno do painel · atualizado em 04/08/2026

Manual de uso — Escala EBD

Este guia reúne o funcionamento atual do painel: lições armazenadas na Hostinger, links externos, programação trimestral, liberação automática na segunda-feira, escala de professores, cadastros, quizzes, histórico e publicação do projeto.

Regra principal: antes de salvar, confira a aba correta, o formato da lição, as datas das aulas, os links e a classe. Depois do salvamento, confirme o resultado no site público.

🔐 Como entrar no painel

  1. Acesse admin.html pelo endereço administrativo.
  2. Digite a senha administrativa.
  3. Clique em Acessar painel.
  4. Use o menu lateral para abrir cada área.

A senha usada na API de lições deve ser a mesma configurada em config.php na Hostinger.

🌐 Página pública

Depois de qualquer alteração, confira:

https://escala.ebdfiel.com.br/

Se a versão antiga aparecer, use Ctrl + F5, aba anônima ou limpe o cache da PWA.

🧩 Onde cada parte fica

  • GitHub Pages: index.html, admin.html e arquivos visuais.
  • Hostinger: API e dados das lições.
  • Google Apps Script/Sheets: escala, professores, quizzes e histórico.

📁 Endereço da API de lições

https://ebdfiel.com.br/escala-ebd-api/licoes.php

Ao abrir esse endereço, a resposta deve conter "sucesso": true.

🏗️ 1. Arquitetura atual do sistema

  • O site e o painel são publicados no GitHub Pages.
  • As lições são salvas na Hostinger, dentro da pasta escala-ebd-api.
  • A escala e os demais dados administrativos continuam no Google Sheets, acessados pelo Apps Script.
  • Não apague nem substitua manualmente storage/licoes.json quando já houver lições cadastradas.
  • O arquivo config.php guarda a senha da API e os domínios autorizados.

Arquivos da API na Hostinger

public_html/escala-ebd-api/
  • .htaccess
  • config.php
  • licoes.php
  • storage/.htaccess
  • storage/licoes.json

📚 2. Como escolher a aba de lições

  1. Clique em Lições interativas.
  2. Abra a aba Jovens e Adultos ou Adolescentes.
  3. Escolha um dos três formatos: Conteúdo HTML, Link externo individual ou Programação trimestral.
  4. Configure somente a aba que deseja alterar.
  5. Antes de salvar, confira se a outra aba não ficou em programação trimestral vazia.

Chaves internas usadas pelo sistema

  • adultos = aba Jovens e Adultos
  • jovens = aba Adolescentes

✍️ 3. Formato “Conteúdo HTML”

  1. Em Formato da lição, escolha Conteúdo HTML.
  2. Edite diretamente no Editor visual ou clique em HTML avançado.
  3. Use Atualizar prévia para sincronizar o HTML com o editor visual.
  4. Use Limpar somente quando quiser apagar todo o conteúdo daquela aba.
  5. Clique em Salvar lições na Hostinger.

O botão Salvar sincroniza automaticamente o editor visual e o campo HTML.

🔗 4. Formato “Link externo individual”

  1. Escolha Link externo individual.
  2. Cole um endereço completo iniciado por https://.
  3. Clique em Salvar lições na Hostinger.
  4. Abra o site público e teste o botão da lição.

O link abre em nova aba. Endereços HTTP, javascript:, data: e URLs com usuário/senha embutidos são bloqueados.

📆 5. Programação trimestral das 13 lições

  1. Escolha Programação trimestral (até 13 lições).
  2. Informe em Data da aula — Lição 1 o domingo da primeira aula.
  3. Clique em Gerar 13 datas de aula.
  4. Cole os links no campo Colar vários links de uma vez, um por linha.
  5. Clique em Distribuir links nas 13 lições.
  6. Revise os títulos, as datas e os endereços.
  7. Confirme se o resumo mostra 13 de 13 lições programadas.
  8. Clique em Salvar lições na Hostinger.

Formatos aceitos na colagem em massa

  • Um link HTTPS por linha.
  • Título da lição | https://endereco-da-licao.
  • Título em uma linha e o link na linha seguinte.

🕛 6. Regra de liberação automática

A data informada na programação é a data da aula. O site libera o link na segunda-feira anterior, às 00h, no horário de Brasília.

  • Exemplo: aula no domingo 16/08/2026.
  • Liberação automática: segunda-feira 10/08/2026 às 00h.
  • A lição permanece ativa até a liberação da próxima.
  • Depois da última aula, a Lição 13 continua disponível.

No modo automático, não é necessário entrar semanalmente no painel.

📌 7. Seleção automática ou fixação manual

  1. Em Lição exibida no site, deixe Automática, conforme a data para seguir o calendário.
  2. Para uma exceção, escolha Fixar manualmente a Lição X.
  3. Salve novamente na Hostinger.
  4. Quando quiser voltar ao calendário normal, selecione Automática, conforme a data e salve.

A fixação manual interrompe temporariamente a troca automática.

💾 8. Como salvar, carregar e conferir as lições

  1. Clique em Salvar lições na Hostinger.
  2. Aguarde a mensagem de sucesso.
  3. Use Carregar versões atuais para reler o que já está salvo na Hostinger.
  4. Abra o site público e atualize a página.
  5. Teste o botão da lição em cada classe.

Atenção: “Carregar versões atuais” não salva alterações; ele apenas recarrega os dados já gravados.

📅 9. Como alterar professor em uma data da escala

  1. Clique em Gerenciar escala.
  2. Na área Alterar professor por data, escolha a data.
  3. Escolha a classe.
  4. Digite o nome correto do professor.
  5. Clique em Salvar alteração.
  6. Confira a tabela da escala e o site público.

➕ 10. Como adicionar uma nova data na escala

  1. Clique em Gerenciar escala.
  2. Vá até Nova data na escala.
  3. Escolha a data do domingo.
  4. Preencha o professor de cada classe.
  5. Clique em Adicionar data.
  6. Confira a tabela e o site público.

🗑️ 11. Como remover uma data

  1. Clique em Gerenciar escala.
  2. Vá até Remover data.
  3. Escolha a data.
  4. Clique em Remover.
  5. Confirme somente se tiver certeza.
  6. Confira se a data saiu da tabela e do site público.

Cuidado: remover data apaga aquela linha da escala.

🏷️ 12. Como renomear uma classe

  1. Clique em Gerenciar escala.
  2. Vá até Renomear classe.
  3. Escolha a classe atual.
  4. Digite o novo nome.
  5. Clique em Renomear.
  6. Confira a tabela e o site público.

👥 13. Como adicionar, editar ou inativar professor

Adicionar professor

  1. Clique em Professores.
  2. Digite o nome na área Novo professor.
  3. Escolha a classe preferencial e o status.
  4. Adicione uma observação, se necessário.
  5. Clique em Adicionar.

Editar ou inativar

  1. Selecione o professor em Editar / Inativar.
  2. Altere nome, classe, status ou observação.
  3. Clique em Salvar alterações.

🔄 14. Como substituir professor na escala

  1. Clique em Professores.
  2. Na área Substituir professor na escala, escolha quem saiu.
  3. Digite ou escolha o novo professor.
  4. Escolha a classe e o período da substituição.
  5. Defina se deseja inativar o professor antigo.
  6. Clique em Substituir.

📌 15. Como mudar professor de classe

  1. Clique em Professores.
  2. Na área Mudar professor de classe, escolha o professor.
  3. Escolha a nova classe.
  4. Escolha se deseja aplicar também na escala.
  5. Clique em Mudar classe.

🧠 16. Como atualizar os quizzes

  1. Clique em Quizzes.
  2. Cole o link do quiz de Jovens e Adultos.
  3. Cole o link do quiz dos Adolescentes.
  4. Clique em Salvar links dos quizzes.
  5. Use Testar links.
  6. Confira os botões na página pública.

🗺️ 17. Como usar o Mapa do Site

  1. Clique em Mapa do Site.
  2. Aguarde mapa-site.html carregar.
  3. Use Recarregar mapa, se necessário.
  4. Use Abrir em nova aba para visualizar separado.

O mapa pode ser atualizado pelo GitHub Actions quando arquivos importantes forem alterados.

📜 18. Como consultar as trocas feitas pelos professores

  1. Clique em Trocas dos professores.
  2. O painel mostrará as alterações realizadas pelos professores na página pública.
  3. Confira data e hora, professor solicitante, classe, data original, nova data e professor envolvido.
  4. Use os filtros por professor, classe e período para localizar um registro.
  5. Clique em Exportar CSV para baixar a consulta.
  6. Use Atualizar para buscar os registros mais recentes no Google Sheets.

Observação: esta área não registra suas ações administrativas. Ela mostra somente as trocas feitas pelos professores pelo site público.

📦 19. Encerramento e mudança de trimestre

  1. Abra Escalas salvas e confira se a automação está ativa.
  2. Depois da última data, o sistema verifica e arquiva a escala.
  3. Quando o arquivo estiver completo, Preparar próximo trimestre será liberado.
  4. Confirme digitando PREPARAR.
  5. O sistema cria os domingos, preserva as classes e continua a sequência dos professores.
  6. Antes da substituição, é criado um backup oculto da escala anterior.

Importante: a preparação do novo trimestre exige confirmação administrativa.

🚀 20. Quando publicar no GitHub, Hostinger ou Apps Script

GitHub Pages

Substitua arquivos no GitHub quando houver atualização de index.html, admin.html, imagens, manifestos ou scripts visuais.

Hostinger

Substitua arquivos na Hostinger quando houver atualização de licoes.php, config.php ou da estrutura da API.

Evite substituir storage/licoes.json, pois ele contém as lições cadastradas.

Google Apps Script

Atualize e implante uma Nova versão somente quando o arquivo Code.gs for alterado.

🧯 21. Problemas comuns

“Senha administrativa incorreta” ao salvar lições

  1. Abra public_html/escala-ebd-api/config.php na Hostinger.
  2. Confira a constante EBD_ADMIN_PASSWORD.
  3. Ela deve ser igual à senha usada para entrar no painel.
  4. Salve, saia do painel e entre novamente.

“Failed to fetch” ao salvar lições

  1. Abra config.php.
  2. Confira se https://escala.ebdfiel.com.br está em EBD_ALLOWED_ORIGINS.
  3. Salve e atualize o painel com Ctrl + F5.

“Não há nenhuma lição completa na programação”

  1. Confira se cada linha possui data da aula e link HTTPS.
  2. Confira se o resumo mostra a quantidade programada.
  3. Se a outra aba não será programada, mude-a para HTML ou link individual.
  4. Salve novamente.

Alterei no painel, mas o site continua antigo

  1. Use Ctrl + F5.
  2. Teste em aba anônima.
  3. Se usa o aplicativo instalado, limpe o cache ou reinstale a PWA.
  4. Aguarde a publicação do GitHub Pages, quando arquivos do GitHub tiverem sido substituídos.

A API abre com erro 500 ou página em branco

  1. Confira se a pasta está em public_html/escala-ebd-api.
  2. Confira se existem config.php, licoes.php e a pasta storage.
  3. Verifique permissões: pastas normalmente 755 e arquivos normalmente 644.
  4. Teste novamente o endereço da API.
Checklist final: aba certa, formato certo, datas das aulas conferidas, links HTTPS válidos, salvamento concluído e teste feito no site público.
