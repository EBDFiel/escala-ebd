🗺️ Mapa automático do Site Escala EBD

Este é o mapa inicial. Depois que o GitHub Actions rodar, este arquivo será substituído automaticamente por uma versão técnica gerada a partir dos arquivos index.html, admin.html e Code.gs.

Como ativar

  1. Criar a pasta .github/workflows.
  2. Adicionar o arquivo atualizar-mapa-site.yml.
  3. Criar a pasta scripts.
  4. Adicionar o arquivo gerar-mapa-site.js.
  5. Subir este arquivo mapa-site.html.
  6. Fazer commit.
