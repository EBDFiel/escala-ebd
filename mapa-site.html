14. Como publicar alterações

Quando alterar index.html ou admin.html

  1. Substituir o arquivo no GitHub.
  2. Fazer commit.
  3. Aguardar o GitHub Pages atualizar.
  4. Abrir o site e usar Ctrl + F5.

Quando alterar Code.gs

  1. Colar o código no Apps Script.
  2. Conferir SENHA_ADMIN.
  3. Salvar.
  4. Implantar como Nova versão.
