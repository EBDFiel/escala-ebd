📘 Manual interno do painel

Manual de uso — Escala EBD

Use este guia sempre que precisar atualizar lições, escala, professores, quizzes, mapa do site ou conferir o histórico. As alterações comuns feitas aqui no admin são salvas no Google Sheets e aparecem na página pública depois da atualização.

Regra principal: antes de salvar qualquer alteração, confira se escolheu a data certa, a classe certa, o professor certo e depois confirme no site público usando Ctrl + F5.

🔐 Como entrar no painel

  1. Acesse admin.html.
  2. Digite a senha administrativa.
  3. Clique em Acessar painel.
  4. Use o menu lateral para navegar pelas áreas.

🌐 Página pública

Depois de qualquer alteração, confira a página pública:

https://ebdfiel.github.io/escala-ebd/

Se algo não aparecer, atualize com Ctrl + F5 ou teste em aba anônima.

📌 Quando usar o GitHub?

Use o GitHub somente quando for alterar arquivos do projeto, como:

  • index.html
  • admin.html
  • Code.gs
  • scripts do mapa automático

⚙️ Quando usar Apps Script?

Use o Google Apps Script somente quando o arquivo Code.gs for alterado.

Depois de alterar o Code.gs, sempre implante como Nova versão.

📚 1. Como atualizar a lição da semana

  1. Clique em Lições interativas.
  2. Escolha Jovens e Adultos ou Adolescentes.
  3. Clique em HTML avançado, se for colar uma lição pronta em HTML.
  4. Apague o conteúdo antigo, se quiser substituir tudo.
  5. Cole o novo conteúdo da lição.
  6. Clique em Sincronizar.
  7. Clique em Salvar lições.
  8. Abra o site público e confira os botões da lição.

Chaves usadas pelo sistema

  • adultos = Jovens e Adultos
  • jovens = Adolescentes

📅 2. Como alterar professor em uma data da escala

  1. Clique em Gerenciar escala.
  2. Na área Alterar professor por data, escolha a data.
  3. Escolha a classe.
  4. Digite o nome correto do professor.
  5. Clique em Salvar alteração.
  6. Confira a tabela da escala no admin.
  7. Abra o site público e confira a alteração.

➕ 3. Como adicionar uma nova data na escala

  1. Clique em Gerenciar escala.
  2. Vá até Nova data na escala.
  3. Escolha a data do domingo.
  4. Preencha o professor de cada classe.
  5. Clique em Adicionar data.
  6. Confira a tabela da escala e depois o site público.

Ordem correta das classes

  1. 1. Cordeirinhos de Cristo
  2. 2. Soldadinhos de Cristo
  3. 3. Heróis e Amigos
  4. 4. Vencedores por Cristo
  5. 5. Vivendo em Cristo
  6. 6. Testemunhas de Cristo
  7. 7. Sara
  8. 8. Heróis da Fé

Atenção: Suporte não é classe. Suporte é apenas uma função do Ronan.

🗑️ 4. Como remover uma data

  1. Clique em Gerenciar escala.
  2. Vá até Remover data.
  3. Escolha a data que deseja remover.
  4. Clique em Remover.
  5. Confirme somente se tiver certeza.
  6. Confira se a data saiu da tabela e do site público.

Cuidado: remover data apaga aquela linha da escala.

🏷️ 5. Como renomear uma classe

  1. Clique em Gerenciar escala.
  2. Vá até Renomear classe.
  3. Escolha a classe atual.
  4. Digite o novo nome.
  5. Clique em Renomear.
  6. Confira a tabela e o site público.

Evite renomear classes sem necessidade, para não confundir a escala e os cadastros.

👥 6. Como adicionar ou editar professor

Adicionar professor

  1. Clique em Professores.
  2. Na área Novo professor, digite o nome.
  3. Escolha a classe preferencial.
  4. Escolha o status: Ativo ou Inativo.
  5. Adicione uma observação, se necessário.
  6. Clique em Adicionar.

Editar ou inativar professor

  1. Na área Editar / Inativar, selecione o professor.
  2. Altere nome, classe, status ou observação.
  3. Clique em Salvar alterações.
  4. Para deixar de usar o professor, altere para Inativo ou clique em Inativar.

🔄 7. Como substituir professor na escala

  1. Clique em Professores.
  2. Na área Substituir professor na escala, escolha o professor que saiu.
  3. Digite ou escolha o novo professor.
  4. Escolha a classe, se quiser limitar a substituição.
  5. Escolha se a troca vale para datas futuras ou para toda a escala.
  6. Escolha se deseja inativar o professor antigo.
  7. Clique em Substituir.

📌 8. Como mudar professor de classe

  1. Clique em Professores.
  2. Na área Mudar professor de classe, escolha o professor.
  3. Escolha a nova classe.
  4. Escolha se deseja aplicar também na escala.
  5. Clique em Mudar classe.

🧠 9. Como atualizar os quizzes

  1. Clique em Quizzes.
  2. Cole o link do quiz de Jovens e Adultos.
  3. Cole o link do quiz dos Adolescentes.
  4. Clique em Salvar links dos quizzes.
  5. Use Testar links para abrir os quizzes.
  6. Confira os botões na página pública.

Chaves usadas pelo sistema

  • adultos = Quiz Jovens e Adultos
  • jovens = Quiz Adolescentes

🗺️ 10. Como usar o Mapa do Site

  1. Clique em Mapa do Site.
  2. Aguarde o arquivo mapa-site.html carregar.
  3. Use Recarregar mapa, se necessário.
  4. Use Abrir em nova aba, se quiser visualizar separado.

O mapa é atualizado pelo GitHub Actions quando arquivos importantes são alterados no GitHub.

📜 11. Como consultar o histórico

  1. Clique em Histórico.
  2. Veja os registros de alterações.
  3. Clique em Atualizar, se quiser recarregar a lista.

O histórico ajuda a conferir alterações de professor, data, classe, origem da ação e trocas feitas pelo site público.

🧯 12. Problemas comuns

Alterei no admin, mas não apareceu no site público

  1. Abra a página pública.
  2. Aperte Ctrl + F5.
  3. Teste em aba anônima.
  4. Aguarde alguns minutos e tente de novo.

Botão do admin não responde

  1. Aperte F12.
  2. Abra a aba Console.
  3. Veja se aparece algum erro em vermelho.
  4. Atualize com Ctrl + F5 e tente novamente.

Lição ou quiz não atualizou

  1. Volte na aba correta do admin.
  2. Carregue as informações atuais.
  3. Salve novamente.
  4. Atualize a página pública com Ctrl + F5.
Checklist final: aba certa, data certa, classe certa, professor correto, salvamento concluído e conferência feita no site público.
